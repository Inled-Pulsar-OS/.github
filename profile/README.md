PulsarOS is a lightweight, modern, stable and secure Linux distribution based on Debian. Its goal is to replicate the look and feel of macOS, with a Windows-inspired flavour planned for the future.

Built in the open and with community involvement, PulsarOS is 100% auditable: every build runs from a public Github Action, and every package is public, auditable, or sourced directly from Debian.

It combines proven stable software like GNOME with alternatives such as SDDM and rEFInd (replacing GDM and GRUB, respectively). Updates are delivered via APT and official Debian repositories.

## Flavours

| Flavour | Description | Status |
|---|---|---|

| **Wintux** | Windows-inspired flavour | Planned |

## Contribute

We are fully open to contributions. If you would like to help, read the [contributing guide](https://github.com/Inled-Pulsar-OS/DOCS/wiki/Contribute) or reach out on Discord.

---

## Current state

We are moving from being users who develop GNOME extensions and apps to building a full distribution. This is new territory, and we welcome feedback on any bumps along the road.

## Community

We want to grow by delegating responsibility, not by concentrating decisions in a handful of people. If you want to become a contributor, get in touch.
